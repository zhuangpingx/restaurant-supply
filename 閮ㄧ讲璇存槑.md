# 餐饮连锁供应链协同系统 - 阿里云部署说明

## 一、服务器要求

- 阿里云 ECS：2核4G 以上（推荐 Ubuntu 22.04）
- 开放端口：80、443、3000
- Node.js 18+、PM2、Nginx

## 二、Supabase 配置（必须先做）

### 1. 注册并新建项目
- 访问 https://supabase.com
- Region 选 Northeast Asia (Tokyo)
- Settings → API 记录三个值：Project URL、anon key、service_role key

### 2. 执行数据库
SQL Editor 里执行 supabase/schema.sql 全部内容

### 3. 创建 Storage
```sql
INSERT INTO storage.buckets (id, name, public)
VALUES ('delivery-photos', 'delivery-photos', true);

INSERT INTO storage.buckets (id, name, public)
VALUES ('payment-proofs', 'payment-proofs', true);

CREATE POLICY "storage_insert" ON storage.objects
FOR INSERT TO authenticated
WITH CHECK (bucket_id IN ('delivery-photos', 'payment-proofs'));

CREATE POLICY "storage_select" ON storage.objects
FOR SELECT TO authenticated
USING (bucket_id IN ('delivery-photos', 'payment-proofs'));
```

### 4. 添加收货员角色
```sql
ALTER TYPE user_role ADD VALUE IF NOT EXISTS 'receiver';

CREATE TABLE IF NOT EXISTS public.store_receivers (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id    UUID NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
  store_id   UUID NOT NULL REFERENCES public.stores(id) ON DELETE CASCADE,
  is_active  BOOLEAN NOT NULL DEFAULT true,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(user_id, store_id)
);

ALTER TABLE public.store_receivers ENABLE ROW LEVEL SECURITY;

CREATE POLICY "receivers_select" ON public.store_receivers
  FOR SELECT USING (user_id = auth.uid() OR get_user_role() = 'boss');

CREATE POLICY "receivers_all_boss" ON public.store_receivers
  FOR ALL USING (get_user_role() = 'boss');

CREATE POLICY "deliveries_select_receiver" ON public.deliveries
  FOR SELECT USING (
    get_user_role() = 'receiver' AND
    store_id IN (
      SELECT store_id FROM public.store_receivers
      WHERE user_id = auth.uid() AND is_active = true
    )
  );

CREATE POLICY "deliveries_update_receiver" ON public.deliveries
  FOR UPDATE USING (
    get_user_role() = 'receiver' AND
    store_id IN (
      SELECT store_id FROM public.store_receivers
      WHERE user_id = auth.uid() AND is_active = true
    )
  );
```

## 三、阿里云服务器部署

### 1. 连接服务器
```bash
ssh root@你的服务器IP
```

### 2. 安装 Node.js 18
```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v
```

### 3. 安装 PM2 和 Nginx
```bash
npm install -g pm2
sudo apt-get install -y nginx
```

### 4. 上传项目
在本地电脑执行：
```bash
scp -r restaurant-supply root@你的服务器IP:/var/www/
```

### 5. 创建环境变量
```bash
cd /var/www/restaurant-supply
nano .env.local
```
填入：
```
NEXT_PUBLIC_SUPABASE_URL=你的URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=你的anon_key
SUPABASE_SERVICE_ROLE_KEY=你的service_role_key
NEXT_PUBLIC_APP_URL=http://你的服务器IP
```

### 6. 安装依赖并构建
```bash
npm install
npm run build
```

### 7. PM2 启动
```bash
pm2 start npm --name "supply-chain" -- start
pm2 save
pm2 startup
```

### 8. 配置 Nginx
```bash
sudo nano /etc/nginx/sites-available/supply-chain
```
内容：
```nginx
server {
    listen 80;
    server_name 你的服务器IP;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_cache_bypass $http_upgrade;
    }
}
```
执行：
```bash
sudo ln -s /etc/nginx/sites-available/supply-chain /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

### 9. Supabase 回调地址
Authentication → URL Configuration：
```
Site URL: http://你的服务器IP
Redirect URLs: http://你的服务器IP/**
```

## 六、角色说明
| 角色 | 说明 |
|------|------|
| boss | 老板，看全部数据，管理账号 |
| store_manager | 店长，管理本店送货单 |
| receiver | 收货员（后厨等），确认送货单 |
| supplier | 供应商，提交送货单 |
| finance | 财务，标记付款 |

## 九、AI 识别功能配置（可选）

如需启用送货单图片 AI 自动识别功能：

1. 访问 https://console.anthropic.com 获取 API Key
2. 在 .env.local 中添加：
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
3. 重新构建部署

不配置此项则 AI 识别按钮不可用，其他功能不受影响。

## 十、阿里云短信配置

在 .env.local 中添加：
```
ALIYUN_ACCESS_KEY_ID=你的AccessKeyID
ALIYUN_ACCESS_KEY_SECRET=你的AccessKeySecret
ALIYUN_SMS_SIGN_NAME=你的签名名称
ALIYUN_SMS_TEMPLATE_CODE=SMS_xxxxxxxx
```

同时在 Supabase SQL Editor 执行（创建OTP验证码临时表）：
```sql
CREATE TABLE IF NOT EXISTS public.otp_codes (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  phone      TEXT NOT NULL,
  code       TEXT NOT NULL,
  expires_at TIMESTAMPTZ NOT NULL,
  used       BOOLEAN NOT NULL DEFAULT false,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_otp_phone ON public.otp_codes(phone);

-- 自动清理过期验证码
CREATE OR REPLACE FUNCTION cleanup_otp_codes()
RETURNS void LANGUAGE plpgsql AS $$
BEGIN
  DELETE FROM public.otp_codes WHERE expires_at < NOW() - INTERVAL '1 hour';
END;
$$;
```
